# SIGEF / SJ Topografia

Repositório público da **SJ Topografia** para organização e distribuição de recursos relacionados a geotecnologia, SIGEF e uso em campo.

## Projeto QField

A documentação e os projetos prontos para QGIS/QField ficam no subprojeto:

[`qfield/`](qfield/)

A arquitetura atual prevê **54 projetos independentes**:

- 27 projetos WMS, um por UF;
- 27 projetos WFS, um por UF.

Os projetos WMS e WFS são distribuídos separadamente.
