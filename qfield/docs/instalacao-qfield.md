# Instalação no QField

Cada UF possui dois projetos independentes:

```text
SJ_GeoField_WMS_UF.qgz
SJ_GeoField_WFS_UF.qgz
```

Exemplo para Minas Gerais:

```text
SJ_GeoField_WMS_MG.qgz
SJ_GeoField_WFS_MG.qgz
```

## WMS

Use quando o objetivo principal for navegação, referência visual e consulta cartográfica em campo.

## WFS

Use quando precisar de geometria vetorial, atributos e seleção de feições.

## Abrir no QField

1. Baixe o `.qgz` da UF e modalidade desejadas.
2. Transfira o arquivo para o dispositivo móvel.
3. Abra o QField.
4. Importe ou abra o projeto local.
5. Mantenha conexão com a internet para os serviços online.

O arquivo `.qgz` local não é vinculado a um usuário específico do QField. Recursos do QFieldCloud, quando utilizados, seguem a conta autenticada no aplicativo.
