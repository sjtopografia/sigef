# Fontes de dados

## INCRA / Acervo Fundiário

Temas previstos por UF:

| Camada | Tema |
|---|---|
| SIGEF - Certificados Particular | `certificada_sigef_particular_{uf}` |
| SIGEF - Certificados Público | `certificada_sigef_publico_{uf}` |
| SNCI - Imóveis Certificados Privado | `imoveiscertificados_privado_{uf}` |
| SNCI - Imóveis Certificados Público | `imoveiscertificados_publico_{uf}` |
| Parcelas Georreferenciadas | `parcelageo_{uf}` |
| Assentamentos | `assentamentos_{uf}` |
| Reconhecimento | `reconhecimento_{uf}` |
| Quilombolas | `quilombolas_{uf}` |

O marcador `{uf}` representa a sigla estadual em letras minúsculas.

Exemplo:

`certificada_sigef_particular_mg`

A disponibilidade efetiva de WMS e WFS depende da resposta do serviço OGC correspondente.
